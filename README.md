# Charles Tay

Workplace learning designer in Singapore, in learning and development since 2004. I don't write code, but I build with AI: live pages on Singapore public data, short explainer cartoons and music videos.

**Site:** [charlestaysg.github.io](https://charlestaysg.github.io) · **Videos:** [youtube.com/@CharlesTay](https://www.youtube.com/@CharlesTay) · **Contact:** [LinkedIn](https://www.linkedin.com/in/charlestay)

## Live pages

| Page | What it does |
|---|---|
| [Singapore Haze, Hourly](https://charlestaysg.github.io/projects/sg-haze/) | NEA's 1-hour PM2.5 next to the US AQI for each region, with wind, rain forecast and a GP finder |
| [Live Workplace Conditions](https://charlestaysg.github.io/projects/workplace-conditions/) | Heat stress for outdoor workers, turned into MOM's rest and water guidance |

All unofficial. The government agencies named on each page are the official sources.

## How I build

Claude Code for the work itself; HyperFrames for motion graphics; Kokoro and Whisper for offline voices and timings; GarageBand, MiniMax-Music3 and Mureka for music; Blender for 3D. Data pages are plain HTML on GitHub Pages, refreshed by GitHub Actions.

The cartoon and music pipeline is open source: [zero-cost-video-toolkit](https://github.com/charlestaysg/zero-cost-video-toolkit).

## Tools I plan to use for teaching

- [CodeShare](https://codeshare.io/): a free shared text editor with no sign-up, so learners can write and compare a prompt together in one document.
- [Padlet](https://padlet.com/): an online board where learners post text, images and links on one shared page, to gather everyone's ideas or questions in one place.

## Working with me

My DISC profile (Discflow) is Steadiness, leaning Compliance. In practice:

- I follow through. If I say I'll do it, it gets done, and checked.
- I think before I answer. If you need a decision now, say so; otherwise I'll come back with a considered one, usually within a day.
- Clear briefs get my best work. Tell me what good looks like. If priorities change, a one-line heads-up helps.
- I'm quiet in big groups. Ask what I think, or message me after; I usually have a view.
- Tell me directly when you disagree. I'd rather hear it than guess.

SCARF says the same from another angle: give me the plan early, leave the how to me, and change I choose is fine.
